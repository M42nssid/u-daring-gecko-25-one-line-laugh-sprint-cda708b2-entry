# One-Line Laugh Sprint

Entry for the make.fun competition
[u-daring-gecko-25-one-line-laugh-sprint-cda708b2](https://make.fun/c/u-daring-gecko-25-one-line-laugh-sprint-cda708b2)
("One-Line Laugh Sprint").

`main.ts` writes a single original one-liner about everyday life
(≤ 200 characters) to `/output/entry.txt`, deterministically,
using only the Node standard library.
